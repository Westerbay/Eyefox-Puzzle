# Third-party assets

This web version reuses artwork already included in the Android project on
`main`. All copied files keep their original pixels and filenames.

- `src/assets/full_cell.png` and `empty_cell.png`: tile artwork from
  `app/src/main/res/drawable`. The original README credits
  [Pixel Art GUI Elements by Mounir Tohami](https://mounirtohami.itch.io/pixel-art-gui-elements)
  for the game's GUI assets.
- `src/assets/awake1.png` and `stand1.png`: fox artwork from the same Android
  resource directory. The original README credits
  [2D Pixel Art Fox Sprites by Elthen](https://elthen.itch.io/2d-pixel-art-fox-sprites).

The GPL license applies to project code. Third-party artwork retains its
respective creators' terms; this project does not grant a separate license to
redistribute those assets by themselves. The original repository does not
include individual asset license files.

The Android project's other credits (Monogram by datagoblin and backgrounds by
Szadi art) remain in the main-branch README. Those assets are not shipped by this
component.
